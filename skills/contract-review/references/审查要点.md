# 合同审查要点（判定细则）

## 一、typo 错别字
**判定**：可根据上下文合理还原的错字、漏字、多字、别字。
- 例：「提共」→「提供」；「完城」→「完成」；「适宜」→「事宜」；「咨共同遵守」→「资共同遵守」。
- 数字写法错误（如"1O0"）也属 typo。

**定位**：定位到段落编号；**同段多个错字合并为一条**。
**修订**：纠正错字，保留原意与有效约定，不得改动无关内容。

## 二、inconsistency 上下文不一致
**判定**：同一主体或事项的**名称、金额、日期、数量、义务**表述相互冲突。
- 例：同一乙方在不同段写作「远山办公设备有限公司」与「北辰办公设备有限公司」。
- 例：合同总价 2200 元，而单价 100 × 数量 20 = 2000 元。
- 例：约定 50% 付款，但「即 X 元」与总价×50% 不符。

**定位**：
- 跨段冲突必须列出**全部**冲突位置（含冲突的每一侧），不能只报准备修改的一侧；
- 连续区间写 `[[s,e]]`；不连续写多个单点区间，如 `[[1,1],[3,3]]`；
- **严禁**为连接两处而包含无关的中间段。

**不算冲突（勿误判）**：合法简称；不同标的/不同事项的正常差异；合同内已明确有效的变更或优先约定。

**修订**：
- 选择一套可成立的取值，并**同步所有必要关联位置**（名称/数值/计算关系/义务）；
- 算术冲突按关系重算（单价×数量、比例×基数），保留原有输入量，不凭空造第三套条件；
- 全文无优先约定时取任一可行值，但全文必须统一。

## 三、missing_element 要素缺失
**判定**：**已有条款内部**缺少必要信息。典型：
- 交付/交货时间、付款时间、金额、数量、违约责任等关键要素未给出具体值；
- 条款仍写「另行协商」「另行约定」「待定」或留空。

**不算缺失（勿误判）**：信息在全文其他条款已明确、可对应推导的，不因当前段未重复填写而认定缺失；「详见附件」若附件可得，一般不算。

**修订**：
- 必须补出**具体**信息（如「本合同生效后10个工作日内」）；
- 可从全文已知信息推导；全文无法确定时给出合理、内部协调的具体约定；
- **不得只写「另行协商」**。

## 四、定位区间速查
| 情况 | location 写法 |
| --- | --- |
| 单段 | `[[3,3]]` |
| 连续区间 | `[[3,5]]` |
| 不连续位置 | `[[1,1],[3,3]]` |
| 多个区间 | `[[1,2],[7,9]]` |
| 合同无问题 | `[]`（error_type 为 null） |
