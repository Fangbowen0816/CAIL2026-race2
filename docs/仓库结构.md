## 一、内核 `src/cail_race2/`（26 个模块）
| 职责 | 模块 |
|---|---|
| **数据/契约** | `contracts`（解析 `<p id>`/反转义）、`records`（记录与不变量校验）、`submission`（写 JSONL/打包）、`submission_check`（提交硬约束） |
| **事实/检测** | `facts`（正则抽事实）、`verify`（冲突/算术/缺失/stance 线索 + **结构化要素缺失/罚则对等性**）、`hints`（线索块）、`detect`（LLM 定位 + 确定性并入 + 过滤）、`stance_review`（逐条款穷举 stance 审查） |
| **修订/生成** | `revise`（LLM 修订 + 自洽 + 双向一致 + 守卫）、`typo_guard`（错别字修订后置校验）、`fill`（确定性补写）、`repair`（算术修复）、`consistency`（不一致整组统一）、`segments`（切句/拼接/守卫）、`evidence`（证据检索）、`rule_review`（S7 规则复核）、`critique`（不变量自检） |
| **评测** | `evaluate`（官方口径 scorer：4 类权重 1:2:4:3）、`ensemble`（多包并集） |
| **流程** | `stage`/`stages`（可插拔 Stage）、`state`（状态）、`pipeline`（两阶段）、`predictor`（响应归一化 + facts 解析） |
| **LLM/配置** | `llm`（OpenAI 兼容客户端，key 不进 repr/日志）、`prompts`（定位/修订提示）、`env`（极简 .env 加载） |

## 二、Agent 系统（课程作业）
- `agent/config`（provider 加载，优先级 env → models.json → ~/.ksxc/auth.json）
- `agent/tools`（read/write/list/shell + 越界防护）
- `agent/mcp_client`（手写 stdio JSON-RPC：initialize/tools/list/tools/call）
- `agent/skills`（渐进式披露技能目录）、`agent/loop`（tool-calling 循环）
- `agent/review`（复用内核做合同审查，产出批注/报告/两份 JSONL）
- `agent/webui`（Flask 表单 → 跑链 → 返回分数）
- `mcp_eval/server`（MCP 评测服务）、`mcp_eval/scorer`（对接官方口径 scorer）

## 三、脚本 `scripts/`
| 脚本 | 用途 |
|---|---|
| `agent_bench_parallel` | 并行跑 N 份合同出提交包（`--provider/--model/--samples/--force`） |
| `model_sweep` | 多模型并行评测（`--repeat` 取均值，`--semifinal`） |
| `eval_samples` | 官方口径回归（`--semifinal` 切复赛 5 gold） |
| `preflight_submit` | 提交门禁（格式硬约束 + 示例口径） |
| `validate_submission` | 格式自检（0 ERROR 口径） |
| `union_packages` | 多包并集 |
| `compare_packages` | 两包对照（类型/重叠/残余） |
| `run_prelim` / `eval_examples` | 初赛跑分/示例评测 |
| `annotate_typos` / `typo_validate` | 合同错别字集标注 / 错别字模块验证 |
| `annotate_errors` / `recall_check` | 召回验证集标注（missing/stance/inc）/ 逐类型召回检测 |
| `stance_scan` | 批量 stance 审查（`--mode cross` 为 S7.5 跨模型审稿） |
| `apply_typo_guard` | 离线对已生成提交包做后置校验 |
