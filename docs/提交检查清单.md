# 提交前检查清单（CAIL 2026 赛道三）

> 线上额度：初赛/复赛**每天 3 次**。每次提交前逐项打勾，避免浪费额度。

## 一、门禁（必过）
- [ ] `python scripts/preflight_submit.py --contracts resources/datasets/race2_contract_review/contracts.jsonl --localization <f> --revision <f>` → 输出「✅ 允许提交」
- [ ] `python -m pytest -q` 全绿
- [ ] 出分端点用 **ksxc**（`--provider ksxc`）；星流端点更保守、会掉分

## 二、包内容
- [ ] zip 内**仅**两个文件：`localization_predictions.jsonl`、`revision_predictions.jsonl`
- [ ] localization 覆盖**全部 15 个合同**（含无问题合同的空哨兵）
- [ ] `original_text` 与输入段落**逐字一致**（注意 HTML 反转义，如 CAIL-006/13）
- [ ] `error_types` == 该段**定位类型并集**（否则整包退回）
- [ ] 无重复 PID、区间升序不重叠、`correct_answer` 非空且不含 `<p>` 标签

## 三、上线与回退
- [ ] 结果登记到 `docs/提交台账.md`
- [ ] 保留候选包与上一版可回退产物
- [ ] 对照本地示例口径（`scripts/eval_samples.py`）确认无回归

## 常用命令
```bash
# 生成 ksxc 包
python scripts/agent_bench_parallel.py --out outputs/agent_bench --provider ksxc --workers 4 --force
# 门禁
python scripts/preflight_submit.py \
  --contracts resources/datasets/race2_contract_review/contracts.jsonl \
  --localization outputs/agent_bench/localization_predictions.jsonl \
  --revision outputs/agent_bench/revision_predictions.jsonl
```
