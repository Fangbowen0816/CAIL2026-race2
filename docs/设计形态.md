## 三、本轮的**变更记录**

1. **第 7 步（确定性覆盖）→ 降级为兜底**
   - 证据：gold 示例**零贡献**（LLM 版 == gold == 确定性版）；15 合同**负贡献**（拆词病句 3~4 段，且覆盖 LLM）。
   - 新形态：默认**以 LLM 版本为准**；仅当 LLM 未产出或明显越界时启用确定性补写。
   - 归入 **#32**（改为「词边界保护 + 有条件/兜底化」）。

2. **第 8 步 → 只做合法性检查**
   - 明确边界：`critique` 只保合规，**不做内容判断**；内容把关交给 S7。

3. **新增 S7「审稿确认层」**
   - 规则前置（词边界/长度膨胀/改动无关句/引入冲突）→ 模型语义裁定（只做拒绝更安全）→ 拒绝回退原文。
   - 与 #31（约束式生成）配套；尚未建 issue。

4. **归类（S5）方法定为「复用 revise-LLM 输出 kind」**（#28）
   - 不做独立 subagent；不做 ML/embedding（无标签、类别少）。

5. **生成（S6）不做多候选**（#31）
   - 靠「约束 + 完整 evidence」一次写对；不做语义校验器。
