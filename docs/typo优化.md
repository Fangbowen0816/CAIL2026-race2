# 错别字修订模块优化（typo guard）

> 起因：线上 `Rev_typo 61.70`（精度 58.1% / 召回 82.0%，`FP=341`）。目标：**保召回、砍 FP**。
> 参考：pycorrector（EC-LAW 法律域纠错，微调 Qwen 可达 F1 0.94–0.98）+ 混淆集约束思路。

## 一、先验证（改之前必须知道错在哪）

对 45 合同做**字符级 diff 审计**（`scripts/audit_typo_edits.py`）。5 gold 对照：typo 段只做
**1–2 处等长同音替换**（共→供、城→成），与 gold 完全一致 → 机制本身正确。

纯 typo 段（166）的编辑分类（初版）：

| 类别 | 数量 | 判定 |
|---|---:|---|
| 同音替换（措→错） | 179 | ✅ 真纠错 |
| **词序颠倒**（要主→主要、定约→约定、风台→台风） | 36 | ✅ 真纠错（diff 表现为 插入+删除） |
| 少字补全（不足→不足以） | 25 | ✅ 真纠错 |
| 重复字/标点删除、补括号 | 59 | ✅ 真纠错 |
| **集外替换**（甲→乙、达到→弥补） | 33 | ❌ 多为改写 |
| **空白差异**（删空格/Tab/NBSP） | 21 | ❌ 非错字 |
| **当事人/数字变动** | 12 | ❌ 非错字 |
| 非重复删除、长度不等改写 | 15 | ❌ 多为改写 |

→ **结论：确有"改错"（空白/专名/集外/结构 约 81 处），但多数编辑仍是真纠错**；
**词序颠倒与少字是"看起来像垃圾、其实是真纠错"的陷阱**，必须保留。

## 二、优化：`src/cail_race2/typo_guard.py`（确定性后置校验）

| 规则 | 行为 |
|---|---|
| G1 空白保真 | 仅空白差异 → 回退 |
| G2 专名/数字保护 | 当事人称谓（甲/乙/丙/丁）与数字的增删改 → 回退 |
| G3 混淆集闸门 | 汉字替换须"同音或形近"（`resources/confusion/{same_pinyin,same_stroke}.txt` + pypinyin + 补充形近表） |
| G4 词序颠倒 | 相邻 `insert(X)/delete(X)` 配对 → **保留** |
| G5 少字补全 | 插入 1–2 个汉字/常用标点 → **保留** |
| G6 结构/改写 | 长度不等改写、非重复删除 → 回退 |

- 生效范围：**纯 typo 段走全规则**；其他段仅**空白保真**（避免误伤 stance/missing 的合法改写）。
- 迭代到不动点（最多 6 轮）；已接入 `LLMReviseStage`（`guard_records`）。

## 三、检测机制：`scripts/typo_check.py`

无 45 合同 gold，故建**规则代理指标**：
```
合法纠错 legit = 混淆集内替换 + 词序颠倒 + 少字补全 + 重复字/标点删除 + 补括号
违规编辑 viol  = 空白差异 + 当事人/数字变动 + 集外替换 + 非法插入/删除 + 长度不等改写
precision 代理 = legit / (legit + viol)
```
